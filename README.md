# Projetos em Python

Repositório com projetos desenvolvidos durante os estudos de Python.

## Projetos

### Aluguel de Carros (aluguel.py)
Sistema de locação de veículos com cálculo automático do valor total.
- Categorias: carro de luxo ou popular
- Cálculo baseado em quilometragem e dias de locação

### Reajuste Salarial (reajuste.py)
Sistema de cálculo de reajuste salarial com regras de negócio.
- Regras diferenciadas por gênero
- Cálculo baseado no tempo de empresa

### Calculadora (calculadorav2.py)
Calculadora com operações matemáticas básicas.
- Adição, subtração, multiplicação e divisão
- Tratamento para divisão por zero
